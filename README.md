# Python Programming Exercises

A collection of ALX/Holberton learning exercises organized by topic, including Python basics, data structures, exceptions, classes, testing, inheritance, and file I/O.

## Topics and technologies

Python, object-oriented programming, testing.

## Getting started

Open a topic directory and run its individual exercises with the Python version required by that assignment.

## Repository organization

This repository contains educational source code and exercises. Browse the directories and source files for individual implementations; not every exercise is intended to be compiled or run together.

## Technical interview discussion

Explain tradeoffs between data structures, exceptions, and unit tests; pick one exercise to refactor and test.

## Scope

This is a learning/portfolio repository. It is not presented as a production-ready or independently security-audited application. Features and test coverage vary by exercise.
